# Course Progress Checklist

Tick each box as you finish it. Keep your copy in Git (copy this file into your
portfolio repository) so your progress is versioned like everything else in this
course.

**How to use it:** a module counts as done only when its **gate** is met and its
evidence is filed — not when the reading is finished.
