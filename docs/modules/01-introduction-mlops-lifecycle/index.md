## What this module is about

A model that performs well in a notebook is not yet a product. This module gives
you the vocabulary and the mental model of the whole **ML lifecycle** — from data
arriving to a model being retired — and shows, through a realistic incident,
exactly what goes wrong when any stage of it is missing.

By the end you can read an incident report and say *which lifecycle stage failed*,
which is the single most useful diagnostic skill a beginner in MLOps can have.
