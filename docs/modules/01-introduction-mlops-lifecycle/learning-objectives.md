# Learning objectives — Module 01

Read these **before** the lessons so you know what you are aiming at. Each
objective is written so that you can prove it without a teacher marking it.

## Objectives

| ID | By the end of this module you can… | Prove it by… |
|---|---|---|
| **LO 1.1** | Describe the stages of the ML lifecycle from data acquisition to monitoring and retirement | Drawing the diagram from memory and labelling every stage |
| **LO 1.2** | Explain, in plain language, why a model that works in a notebook can still fail in production | Writing ≥3 distinct failure causes from the lab incident, each tied to a stage |
| **LO 1.3** | Distinguish MLOps from DevOps and name at least five ways ML systems differ from conventional software | Answering objectives 4–7 of the knowledge check correctly |
| **LO 1.4** | Draw and annotate an end-to-end MLOps architecture diagram | Submitting the diagram with data, code, model, and feedback arrows labelled |

## What "good" looks like

- **Pass:** all four objectives demonstrably met — diagram drawn, incident summary
  naming three root causes with stages, knowledge check ≥ 7/10.
- **Not yet:** you can recite the definition of MLOps but cannot point to where in
  a system something failed. Redo the lab's task 4 before moving on.

## Vocabulary you must be able to use after this module

**MLOps**, **ML lifecycle**, **training**, **inference**, **model**, **feature**,
**pipeline**, **experiment**, **reproducibility**, **technical debt**, **concept
drift**, **model registry**, **serving**, **monitoring**, **feedback loop**,
**DevOps**, **continuous integration**, **continuous deployment**.

Each is defined in [concepts.md](concepts.md) before first use, and collected in
the course [glossary](../../glossary/index.md). If you cannot define a term
without looking it up, it counts as not yet learned.

## How this module is assessed

- **Knowledge check:** 10 short answers — [knowledge-check.md](knowledge-check.md)
  (attempt first, then mark yourself against the answers and reasoning).
- **Practical:** the lab's graded artefact — [lab.md](lab.md), acceptance
  criteria in §9.
