# MLOps — A Self-Study Course for University Students

**Machine Learning Operations (MLOps)** is the set of practices that takes a
machine-learning (ML) model from a laptop experiment to a system that runs
reliably in production: versioned data and code, reproducible training, automated
testing and deployment, monitoring, and governance.

This is a complete, beginner-to-advanced course in MLOps — **17 modules**, a
guided laboratory in every module, five progressive mini-projects, and an
integrated capstone — written for students learning **on their own**, without an
instructor in the room.

## What you will be able to do

By the end of the course you will be able to:

1. Explain the ML lifecycle and why production ML systems fail without MLOps practices.
2. Build a reproducible, version-controlled ML project from an empty folder.
3. Validate and version data so any experiment can be re-run on identical inputs.
4. Train models reproducibly and track experiments with MLflow.
5. Test ML systems the way software is tested — unit, data, model, integration, regression.
6. Automate pipelines with dependency-aware workflows and CI/CD on GitHub Actions.
7. Register, promote, and serve models behind a tested REST API in a container.
8. Monitor for data and model drift and justify retraining from evidence.
9. Apply security, privacy, fairness, and governance controls to an ML system.
10. Design for scaling and reliability, and integrate the whole lifecycle in a capstone.

## How this course works

- **Concepts before tooling.** Every tool is preceded by the problem it solves.
- **One major new tool at a time**, with alternatives explained rather than hidden.
- **Free and local by default.** Every required activity runs on a normal
  Windows 11 laptop with free, open-source tools. Nothing graded needs a credit card.
- **Evidence over confidence.** Every lab has a ✅ verification step; you keep what
  you produce in a portfolio repository.

### Labels used everywhere in the course

| Label | Meaning |
|---|---|
| 🪟 **Windows / PowerShell** | The primary environment: Windows 11 with PowerShell |
| 🐧 **Linux / macOS** | Equivalent command or step for other operating systems |
| ☁️ **Optional cloud** | Needs an external service and an account — never required |
| 💲 **Paid** | Costs money beyond a free tier — always optional |
| ⚠️ **Resource-heavy** | Needs notable disk, memory, or CPU; guidance is given |
| ✅ **Check yourself** | Run it and confirm the stated output before moving on |
