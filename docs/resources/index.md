# Learning Resources

Carefully selected external material — documentation, free courses, papers, and
communities — matched to the module where it helps. Everything here is free
unless marked 💲.

**Selection rules:** official documentation first; free and openly accessible
before paid; something that teaches *concepts* before something that teaches only
*clicks*; no affiliate links, no trackers, nothing the site depends on to render.

## Why so few links?

Each module should leave you with *doing* rather than *reading*. External material
is deliberately rationed: the goal is that you build things, not collect tabs.
Where the course needs background, it is explained in the lessons themselves.
