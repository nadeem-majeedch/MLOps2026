## The four layers

| Layer | Where | Frequency | Suggested weight |
|---|---|---|---|
| **Knowledge checks** | Each module's assessments | End of each lesson cluster | 15% |
| **Practical labs** | [Labs](../labs/index.md) | 1–2 per module | 35% |
| **Mini-projects** | [Projects](../projects/index.md) | MP1–MP5 across the course | 25% |
| **Integrated capstone** | Module 17 | Once | 25% |

## Suggested self-study thresholds

| Result | Overall | Hard conditions |
|---|---|---|
| **Distinction** | ≥ 85% | "Meets" on every capstone criterion |
| **Merit** | ≥ 70% | No rubric below "Developing"; capstone passes |
| **Pass** | ≥ 50% | All essential labs verified at least once |
| **Not yet** | < 50% | Re-run the failed labs, then re-assess |

## How self-assessment works

1. **Attempt** the task and record your evidence (output, logs, reports).
2. **Grade** against the rubric in the
   [framework](../syllabus/assessment-framework.md) — each criterion has a
   measurable acceptance test, not a vibe.
3. **Note the gaps**, re-attempt after a cooling-off period, and keep both attempts:
   progress is itself evidence.
4. **Attempt first, then check answers.** Keys live in
   [`keys/`](keys/question-banks-KEY.md) and are useless to you if opened
   before you try — they explain *reasoning*, which only helps once you have
   your own.

**Integrity rule:** never record a check as passed without having run it and read
the output. Evidence without execution is not evidence.
