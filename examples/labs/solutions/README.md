# Reference solutions — the 20 labs

**Honest use:** attempt a lab **first**, in full, before opening anything
here. A solution read before the attempt teaches nothing and corrupts the
only evidence you had — that you could do it.

Each `lab-NN/` folder holds an answer key for one lab:

- **Reference answers** to the writing checkpoints (diagnosis, decision,
  verdict, reflection) — modelled on what a strong submission contains,
  not a word-for-word template to paste.
- **Verification transcripts:** the exact commands and what they print
  on a working machine (authoring machine: Windows 11, Python 3.14).
  Re-run them yourself; a transcript is evidence about *my* machine
  until it is reproduced on yours.
- **Common wrong answers** with why they are wrong.

## Rules of engagement

1. Finish the lab's §8 steps and fill in every ✅ checkpoint yourself.
2. Only then open the matching solution folder.
3. Compare **reasoning**, not wording. If your answer differs but the
   evidence chain holds, yours may be better — say so in your write-up.
4. Never copy a transcript and tick a box. The course's grading rule
   (see [assessment framework](../../../docs/syllabus/assessment-framework.md))
   is evidence-before-claim.
